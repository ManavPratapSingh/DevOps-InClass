# Linux Fundamentals

## Task 1: Soft Link & Hard Link
A hard link is an additional directory entry referencing the exact same inode and physical data blocks on disk as the original file. Because it points directly to the inode, deleting or renaming the source file does not affect the hard link or cause data loss. However, hard links cannot span across different filesystems or be created for directories. In contrast, a soft link (symbolic link) acts like a shortcut containing a path string to the target file or directory. It has its own unique inode. If the original file is deleted, the soft link breaks.

## Task 2: adduser vs useradd
`useradd` is a low-level native binary utility present across all Linux distributions. It performs basic account creation without interactive prompts, requiring manual command flags to create home directories or set up default shells. Conversely, `adduser` is a high-level Perl script wrapper available on Debian and Ubuntu. It provides an interactive prompt that automatically creates the user's home directory, populates default files from `/etc/skel`, and prompts for a password. On Ubuntu, `adduser` is preferred for manual administrative user setup because it handles complete account configuration automatically, whereas `useradd` is used for non-interactive scripting.

## Task 3: journalctl
`journalctl` is a command-line utility used to query and inspect log messages generated by the `systemd-journald` service in systemd-based Linux distributions. It centralizes system logging by collecting data from kernel messages, system services, process standard outputs, and early boot logs into a single indexed binary format. System administrators use `journalctl` to troubleshoot service failures, monitor live system events in real-time, audit security access, and filter system log history by specific units, timestamps, or severity priority levels.
